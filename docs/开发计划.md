# SteamExoticism 开发计划

> 个人单机工具。不涉及权限、高并发等企业级问题，以「简单、可维护、快速迭代」为原则。

## 一、总体架构

- **开发形态（日常开发/测试）**：前后端分离。Vite dev server（5173）通过代理把 `/api` 转发到 Spring Boot（18080），无需处理 CORS。
- **成品形态 A（Web）**：前端 `dist` 打包进后端 jar 的 `static/`，只需 `java -jar app.jar` 后浏览器访问即用。
- **成品形态 B（PC 客户端）**：Tauri 2 桌面壳 —— 点击图标打开原生窗口，壳自动拉起后端 jar，窗口加载 `http://127.0.0.1:{实际端口}`，关闭窗口时同步结束后端进程。两种形态共用同一套前后端代码。

## 二、技术选型（已确认）

| 层 | 选型 |
|---|---|
| 前端 | Vue 3 + Vite + TypeScript + Vue Router + Pinia + Axios + Element Plus |
| 后端 | Spring Boot 3.5.16（JDK 17，Maven 构建）+ MyBatis-Plus 3.5.17 + sqlite-jdbc + HikariCP |
| 桌面 | Tauri 2 + `tauri-plugin-shell`（启动后端）+ `tauri-plugin-single-instance`（防重复启动） |

## 三、SQLite 集成要点

- JDBC URL 携带 `journal_mode=WAL&busy_timeout=5000&synchronous=NORMAL&foreign_keys=on`，sqlite-jdbc 会对每条连接生效。
- HikariCP `maximum-pool-size: 1`：单机单连接最稳，规避 `database is locked`。
- 主键 `@TableId(type = IdType.AUTO)` + `INTEGER PRIMARY KEY AUTOINCREMENT`。
- 分页 `PaginationInnerInterceptor(DbType.SQLITE)`；注意 MyBatis-Plus 3.5.9 起分页拦截器已拆出，需额外引入 `mybatis-plus-jsqlparser`。
- 数据库文件 `./data/app.db`（相对运行目录），WAL 模式下可直接拷贝文件备份。

## 四、里程碑

- **M0 环境准备**：git init + .gitignore；安装 Node.js LTS（Rust 工具链推迟到 M5）。
- **M1 后端骨架**：pom、application.yml、统一返回体、全局异常处理、MyBatis-Plus 分页配置、`/api/health` 健康检查（含数据库连通检测）。
- **M2 前端骨架**：Vite 项目、Vite proxy、路由、Pinia、Axios 封装、Element Plus、响应式布局、示例页面打通后端。
- **M3 业务功能迭代**：按「表结构 → API → 页面 → 自测」单模块闭环迭代（随需求逐步加入）。
- **M4 单 jar 集成**：frontend-maven-plugin 在 `mvn package` 时自动构建前端并输出到 `static/`；SPA 回退（非 `/api/**` 未命中路径 forward 到 index.html）；验证 `java -jar` 完整可用。
- **M5 Tauri 桌面壳**：壳以随机端口拉起后端、解析日志获取实际端口、加载页面；窗口关闭杀后端；单实例；jlink 裁剪 JRE 随安装包分发；配置图标；NSIS 安装包。

## 五、风险与注意点

- 分页依赖 `mybatis-plus-jsqlparser`，遗漏会导致分页静默失效（M1 已配置并验证）。
- 桌面壳启动后端有几秒等待，窗口先显示加载态，健康检查通过后再跳转。
- 数据库升级靠后端启动时执行初始化 SQL（个人工具用 schema.sql + 迁移脚本，不引入 Flyway）。
- Spring Boot 3.5.16 已 EOL，但生态最稳、资料最全，个人场景可接受；日后可平滑升 4.x。
